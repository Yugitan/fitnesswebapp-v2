# ADR-002：MVP 暂不引入 AI 和后端

**日期**: 2026-07-26  
**状态**: 已决定  
**决策者**: 产品设计阶段

---

## 背景

项目最初设想包含 AI 私教问答、RAG 检索、DeepSeek API、Meilisearch、pgvector、Supabase 登录与云同步。当前产品方向收敛为动作展示库和健身训练记录。

动作展示和训练记录可以完全在前端完成：动作数据是静态 JSON，训练记录可存入 IndexedDB。继续保留 AI 和后端会增加部署、鉴权、成本控制、安全边界和运维复杂度。

## 决策

MVP 暂不引入 AI 和后端服务。

- 不开发 AI 对话页面
- 不接入 DeepSeek API
- 不建设 RAG 检索链路
- 不部署 Meilisearch 和 pgvector
- 不开发 Supabase 登录和云同步
- 不开发训练计划生成

MVP 只实现：

- 动作库搜索、筛选、详情展示
- 收藏动作和最近动作
- 本地训练记录
- 训练历史和基础统计
- 数据导出/导入

## 影响

- 开发路径更短，首版可更快形成可用产品
- 成本更低，静态部署即可上线
- 安全和合规风险下降
- 产品差异化暂时不依赖 AI，而依赖动作库质量、记录效率和移动端体验
- 后续如用户反馈需要“问动作/做计划”，再基于真实需求决定是否恢复 AI 模块
