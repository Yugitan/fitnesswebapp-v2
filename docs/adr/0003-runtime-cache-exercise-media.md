# ADR-003：动作媒体按需缓存

**日期**: 2026-07-26  
**状态**: 已决定  
**决策者**: 产品设计阶段

---

## 背景

动作库包含 1,324 个缩略图和 1,324 个 GIF。当前本地素材中，图片目录约 11MB，GIF 目录约 125MB。

如果 PWA 安装阶段预缓存全部图片和 GIF，会导致首次加载慢、安装慢、存储占用高，也可能在移动网络下造成明显流量消耗。

## 决策

MVP 采用按需缓存策略：

- 应用壳、核心 JS/CSS、动作 JSON 或搜索索引可预缓存
- 动作列表优先加载缩略图
- GIF 只在动作详情页或用户明确查看时加载
- 缩略图和 GIF 使用 runtime cache
- 不在 Service Worker install 阶段预缓存全部媒体文件

## 影响

- 首屏和安装体验更轻
- 用户看过的动作后续可更快打开
- 第一次打开某个动作详情时仍需要网络加载 GIF
- 后续可以按“收藏动作”“最近动作”“热门动作”扩展更智能的预缓存策略
